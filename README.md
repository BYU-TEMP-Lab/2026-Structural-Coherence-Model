# Structural Coherence Model (SCM) for Molten Salt Thermal Conductivity

This repository contains the code and collected data used for the **Structural Coherence Model (SCM)**, a physics-informed approach to estimate the mean free path for thermal conductivity predictions of molten salts using the **Pair Distribution Function (PDF)**. 

This work is based on the paper:  
> **"Structural Coherence Model for Predicting Molten Salt Thermal Conductivity Informed by the Pair Distribution Function"** (Numbers et al., 2026).

## Overview

By analyzing the $g(r)$ (PDF) of a salt, the model calculates a **Structural Coherence Length (SCL)**, which represents the energy carrier mean free path ($l$).

## Repository Structure

* `SCL_calc.py`: The main Python script used to calculate the Structural Coherence Length and predict thermal conductivity ($k$).
* `PDF_CSV/`: Input directory containing pair/radial distribution data ($g(r)$) in CSV format.
* `SCL_plots/`: Visualizations generated by the model, showing the PDF and the calculated coherence probability for each salt.
* `SCL_results.csv`: A compiled summary of calculated SCL values and PDF analysis esults.

## Data Source Naming Convention

Files in the `PDF_CSV` and `SCL_plots` directories follow a naming convention that identifies the salt, the PDF source author, the temperature, and the method used to generate the PDF data.

The suffix of the file names indicates the **Source Type**:

### Classical Potentials
* **RIM (Rigid Ion Models)**
* **PIM (Polarizable Ion Models)**
* **AP (Advanced Potentials)** 
* * Includes both ab-initio (AIMD/FPMD) and machine-learning potentials (MLIP)
* **Exp**
* * Predominantly Neutron Diffraction Isotopic Substitution (NDIS)

## Getting Started

1. **Requirements:** Ensure you have Python installed with `numpy`, `pandas`, and `matplotlib`.
2. **Input Data:** Place PDF data files (columns for $r$ and $g(r)$, each labeled by elemental ion pair 'Xx-Yy') into the `PDF_CSV/` folder.
3. **Add Salts to Script:** In the bottom *Execution* section, add a function call to specify the PDF CSV file, salt composition, (optional) author label, PDF temperature, (optional) back-calculated SCL, and SavGol filter option
4. **Run the Model:**
   ```bash
   python scl_calc.py
5. **View Results:** Check 'scl_results.csv' for numerical predictions and 'SCL_plots/' for visual analysis.
